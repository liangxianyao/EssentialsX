# EssentialsX 2.22.0 / Paper 1.21.11 限时飞行移植

## 目标

将限时飞行功能移植到 EssentialsX 2.22.0，面向 Paper 1.21.11。玩家凭权限档位首次使用 `/flytime` 时领取一次配置的固定时长；之后用同一命令暂停或恢复。限时只在玩家在线且计时开启时消耗，下线和停服期间不消耗。

## 使用方式

- `/flytime`：有 `essentials.flytime` 和 `essentials.flytime.duration.<档位>` 权限的玩家首次执行时领取一次对应固定时长；已有时长时用于暂停或恢复。
- 额度耗尽后不会再次自动发放。普通玩家不能输入时长为自己补充；拥有 `essentials.flytime.others` 的管理者可用 `/flytime <时长> [玩家]` 补充自己或其他在线玩家，控制台可用 `/flytime <时长> <玩家>` 补充在线玩家。时长单位支持 `s`、`m`、`h`、`d`、`w`。
- 手动执行 `/fly` 会清除限时余额，避免限时结束后飞行状态与手动开关冲突；一次性领取记录仍保留。

## 固定时长配置

在 EssentialsX 的 `config.yml` 中配置权限档位与首次领取的时长，例如：

```yaml
flytime-permission-durations:
  basic: 10m
  vip: 1h
```

`basic` 和 `vip` 是配置档位名，不要求与 LuckPerms 组名相同。分别给对应组授予 `essentials.flytime.duration.basic` 或 `essentials.flytime.duration.vip`；同时还需要 `essentials.flytime`。配置只决定首次领取额度，不会按天重置，也不会在每次开关飞行时重新发放。

已有服务器的 `config.yml` 不会自动加入新字段，需要把上述配置段手工加入服务器现有配置，保留其他设置和玩家数据。配置缺失或档位时长无效时，该档位不会发放额度。

若玩家同时拥有多个有效档位，首次领取配置中最长的时长。只有 `essentials.flytime`、没有任何档位权限的玩家不能自行领取，但仍可用 `/flytime` 暂停或恢复管理员补充的余额。

## LuckPerms 权限组配置步骤

以下按游戏内命令格式书写；在服务器控制台执行时去掉开头的 `/`。

1. 用 `/lp listgroups` 查看当前组名，并将下面的占位名称换成服务器已有的组名。
2. 给允许领取 10 分钟的玩家组添加基础节点和 `basic` 档位节点：

   ```text
   /lp group <玩家组名> permission set essentials.flytime true
   /lp group <玩家组名> permission set essentials.flytime.duration.basic true
   ```

   需要 1 小时档位的组改用 `essentials.flytime.duration.vip`。各档位的时长在 `flytime-permission-durations` 中调整。
3. 给允许替其他玩家补充飞行时长的管理组添加两个管理节点：

   ```text
   /lp group <管理组名> permission set essentials.flytime true
   /lp group <管理组名> permission set essentials.flytime.others true
   ```

   管理组需要基础节点才能使用 `/flytime`；`essentials.flytime.others` 开放手动补充自己或其他玩家的能力。管理者若也要首次领取固定额度，还需授予一个 `essentials.flytime.duration.<档位>` 节点。拥有所有权限节点的管理员会领取配置中最长的档位。
4. 用权限检查确认授权结果：

   ```text
   /lp group <组名> permission check essentials.flytime
   /lp group <组名> permission check essentials.flytime.duration.basic
   /lp group <组名> permission check essentials.flytime.others
   ```

5. 撤销时对相应组执行 `permission unset`，例如：

   ```text
   /lp group <组名> permission unset essentials.flytime
   /lp group <组名> permission unset essentials.flytime.duration.basic
   /lp group <管理组名> permission unset essentials.flytime.others
   ```

玩家组同时需要基础节点与配置档位节点；管理组补充他人时还需要 `essentials.flytime.others`。命令格式参考 [LuckPerms 官方用法](https://luckperms.net/wiki/Usage)。

## 2.22.0 适配要点

- 基于 2.22.0 的玩家数据和命令注册结构，只增加限时到期在线 tick 与暂停余额。
- 到期时间依据玩家累计在线游戏 tick；定时器只检查在线用户。
- 玩家数据持久化一次性领取记录，避免重启、下线、余额耗尽或手动 `/fly` 后重复领取。
- `Settings` 读取 `flytime-permission-durations`，按玩家拥有的有效档位权限取最长时长作为首次领取额度；没有档位时不自领，但可切换管理员已补充的余额。旧配置缺少该项时保留现有数据，需手工加入该段才能开放自动领取。
- 将登录恢复接入 2.22.0 的 `joinFlow`；世界切换时保留有效限时飞行。
- 到期通过现有 `FlyStatusChangeEvent` 关闭飞行；如果事件取消，保留过期状态并在后续检查重试。
- 测试沿用 2.22.0 的 JUnit 5 与 MockBukkit。
